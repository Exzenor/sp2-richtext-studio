SimplePlanes 2 (SP2) için Label ve HUD görsellerini RichText koduna dönüştüren web tabanlı yaratıcı araç.

## Canlı Kullanım (İndirmeden Aç)
Uygulamayı doğrudan tarayıcınızdan kullanmak için:
👉 **https://KULLANICI-ADIN.github.io/sp2-richtext-studio/**

## Özellikler
- PNG / JPG / WEBP görsellerini SP2 `Label.State` uyumlu RichText formatına çevirir.
- Otomatik şeffaf kenar kırpma (Auto-Trim) ve renk birleştirme ile karakter tasarrufu sağlar.
- `Label Width` / `Height` kutu sığma kontrolü ve karakter sayısı performans uyarısı verir.
- Tek tıkla oyun içi (**Copy SP2**) veya XML (**Copy XML**) formatında kopyalama.
- Karanlık/Aydınlık tema, özelleştirilebilir buton/yazı renkleri ve 6 dil desteği (TR, EN, RU, 中文, FR, DE).

# SP2 RichText Studio

A web-based creative tool that converts images into RichText code for SimplePlanes 2 (SP2) Labels and HUDs.

## Live Demo (No Download Required)
Use the application directly in your browser:
👉 **https://YOUR-USERNAME.github.io/sp2-richtext-studio/**

## Features
- Converts PNG / JPG / WEBP images into SP2 `Label.State` compatible RichText format.
- Automatic transparent border cropping (Auto-Trim) and color merging to save characters.
- `Label Width` / `Height` box fit checker and character count performance warnings.
- One-click copy for in-game (**Copy SP2**) or Overload (**Copy XML**) formats.
- Dark/Light mode, customizable button & text colors, and 6 language options (EN, TR, RU, 中文, FR, DE).
