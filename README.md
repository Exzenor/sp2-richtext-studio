# SP2 RichText Studio

SimplePlanes 2 (SP2) için Label ve HUD görsellerini RichText koduna dönüştüren web tabanlı yaratıcı araç.

## Canlı Kullanım (İndirmeden Aç)
Uygulamayı doğrudan tarayıcınızdan kullanmak için:
👉 **https://KULLANICI-ADIN.github.io/sp2-richtext-studio/**

## Özellikler
- PNG / JPG / WEBP görsellerini SP2 `Label.State` uyumlu RichText formatına çevirir.
- Otomatik şeffaf kenar kırpma (Auto-Trim) ve renk birleştirme ile karakter tasarrufu sağlar.
- `Label Width` / `Height` kutu sığma kontrolü ve karakter sayısı performans uyarısı verir.
- Tek tıkla oyun içi (**Copy SP2**) veya XML (**Copy XML**) formatında kopyalama.
- Karanlık/Aydınlık tema, özelleştirilebilir buton/yazı renkleri ve 6 dil desteği (TR, EN, RU, 中文, FR, DE).
